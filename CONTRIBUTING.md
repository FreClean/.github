# Contributing to FreClean

Thank you for your interest in contributing.

1. Fork the relevant repository (`freclean`, `freclean-website`, or `freclean-app`).
2. Create a feature branch: `git checkout -b feature/my-change`.
3. Follow the existing code structure — business logic belongs in `freclean`
   only; the website and app should not duplicate it.
4. Add or update tests for any behavior change.
5. Open a pull request describing what changed and why.

Please review `CODE_OF_CONDUCT.md` and `SECURITY.md` before contributing.
