# FreClean Organization Governance

Organization-wide governance, security policy, reusable CI, and the shared
architecture contract for FreClean's four active repositories.

## Repositories

| Repo | Purpose |
|---|---|
| [freclean](https://github.com/FreClean/FreClean) | Core: backend, API, database, business logic |
| [freclean-website](https://github.com/FreClean/freclean-website) | Public marketing website |
| [freclean-app](https://github.com/FreClean/freclean-app) | Customer / staff / admin application |
| `.github` | Org-wide templates, workflows, security policy |

See [architecture-contract.md](architecture-contract.md) for binding ownership,
API, payment, compatibility, and deployment rules.
