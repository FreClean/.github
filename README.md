# FreClean

Official GitHub organization of FreClean — building the future of professional
cleaning through services, premium products, and entrepreneurship, across
Haiti, the Dominican Republic and the Caribbean.

## Repositories

| Repo | Purpose |
|---|---|
| [freclean](https://github.com/FreClean/FreClean) | Core: backend, API, database, business logic |
| [freclean-website](https://github.com/FreClean/freclean-website) | Public marketing website |
| [freclean-app](https://github.com/FreClean/freclean-app) | Customer / staff / admin application |
| `.github` | Org-wide templates, workflows, security policy |
